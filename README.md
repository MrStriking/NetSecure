Capstone Project:

A website to teach and simulate network security using the GNS3 network sim.
Requires the GNS3 virtual machine which will be accessible in our website.
GNS3 virtual machine download link: https://www.gns3.com/software/download-vm

Capabilities of the default devices in the sim are extremely limited. More features could be added if cisco devices are bought and imported.
Our assesment of the labs currently depends on the GNS3 api and running a set of functions to check very basic stuff like network segmentation.
